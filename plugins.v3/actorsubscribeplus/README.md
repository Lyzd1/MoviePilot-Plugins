# 演员作品订阅（ActorSubscribePlus）

fork 自 [thsrite/MoviePilot-Plugins](https://github.com/thsrite/MoviePilot-Plugins) 的 `plugins.v3/actorsubscribeplus` v2.0.0；本地改造：新增「排除题材」多选（真人秀/脱口秀/新闻/纪录片，默认真人秀+脱口秀），仅对电视剧生效，电影不受影响。

按 TMDB 演员（明星）抓取其全部影视作品，按「订阅类型 / 年份 / 最近上映时间 / 评分」筛选后自动创建订阅，并把每条处理结果记入插件详情页的历史列表。

### 新增配置项：排除题材

- **选项**：真人秀（Reality，TMDB 10764）、脱口秀（Talk，10767）、新闻（News，10763）、纪录片（Documentary，99）。
- **默认值**：`真人秀 + 脱口秀`。
- **生效范围**：**仅对电视剧生效，电影不受影响**。
- **判定口径**：作品在 TMDB 的剧集题材（`genre_ids`）命中任一勾选题材即跳过本条，不做订阅、也不写入「已处理」记录（与「年份不足 / 评分不足」一致，只跳过本轮；改回设置后下一轮仍会重新评估）。
- **关闭过滤**：把「排除题材」全部取消勾选即可（空列表 = 不排除任何题材）。

### ⚠️ 升级行为变化

默认值 `真人秀 + 脱口秀` 会让**升级后的既有行为发生变化**：此前会被自动订阅的真人秀、脱口秀类电视剧，现在会被直接跳过。这是本 fork 的预期行为（起因：《秘密朋友俱乐部》这类被 TMDB 归类为电视剧、实为真人秀的作品被误订阅）。若仍想订阅真人秀/脱口秀，请到插件设置中取消对应勾选。

## 安装

把本目录（`actorsubscribeplus`）放入 MoviePilot 的插件目录后，在市场或插件页安装 `ActorSubscribePlus` 即可。本插件为单文件插件，无前端构建产物，无额外依赖。

## 使用方法

1. 打开插件设置，填写「明星」（多个用英文逗号分割，如 `高允贞,汤唯`）。
2. 按需调整：
   - **执行周期**：5 位 cron 表达式，留空则只做手动运行。
   - **订阅类型**：电影 / 电视剧，多选。
   - **排除题材**：真人秀 / 脱口秀 / 新闻 / 纪录片，多选，默认排除真人秀与脱口秀（仅对电视剧生效）。
   - **年份**：作品年份大于该值才会被订阅。
   - **最近多久上映**：未上映且距今超过该天数的作品不会被订阅。
   - **评分**：TMDB 评分大于该值才会被订阅。
3. 打开「启用插件」，或直接点「立即运行一次」跑一轮。
4. 详情页可查看历史记录（含封面、类型、来源链接），支持单条删除。

## 常见问题

**Q：为什么某部剧明明不是真人秀/脱口秀也被排除了？**
A：判定依据是 TMDB 的题材字段，而不是标题或简介。若 TMDB 对该作品的题材标注有误，可先到 TMDB 修正，或临时取消对应的排除勾选。

**Q：为什么电影里有真人秀题材也不会被排除？**
A：按需求，题材过滤只作用于电视剧（`MediaType.TV`）。电影的题材分类与剧集不同，误伤概率高，故不做过滤。

**Q：排除后还会再被订阅吗？**
A：本轮不会再处理，且不会记入「已处理」列表；但每轮都会重新评估，一旦取消对应勾选，下一轮就会正常订阅。

## 如何同步上游

本目录以上游单文件为基线，改动刻意保持**最小 diff**（仅新增题材相关代码 + 版本/作者两行），便于将来跟随上游更新：

1. 取上游最新文件：
   - 仓库：`https://github.com/thsrite/MoviePilot-Plugins`
   - 路径：`plugins.v3/actorsubscribeplus/__init__.py`
2. 用上游新文件覆盖本地 `__init__.py`，然后重新套用本 fork 的改动（改动点见下），并把 `plugin_version` 提升到高于上游的版本号：
   - 模块级常量与纯函数：`GENRE_EXCLUDE_IDS` / `GENRE_EXCLUDE_NAMES` / `DEFAULT_EXCLUDE_GENRES` / `matched_excluded_genre()`
   - 类属性 `_exclude_genres`
   - `init_plugin` 中读取 `exclude_genres`（缺字段回落默认）
   - `__actor_subscribe` 中「类型判断之后、年份判断之前」的电视剧题材过滤块
   - `__update_config` 中回写 `exclude_genres`
   - `get_form` 中的「排除题材」`VSelect` 与默认值
3. 核对上游是否已经自带同类功能：若上游新增了题材过滤，优先采用上游实现，删除本 fork 的重复逻辑，避免两边分叉。
4. 同步后更新 `package.v3.json` 中 `ActorSubscribePlus` 的 `version`，并在 `history` 里补一条说明（注明对应的上游版本）。
