# 站点分享率上传限速（SiteRatioLimiter）

MoviePilot V2 插件：基于**站点账号分享率（上/下限）**事件驱动地管理 **qBittorrent** 种子的上传限速。

## 功能

- **全局分享率下限/上限**，并可为每个站点单独设置（未配置的站点回退全局值）；
- 插件内部维护每个站点的分享率**档位状态**（🔻低于下限 / ✅正常 / 🔺高于上限 / ⚪无数据），
  由「站点数据统计」插件的分享率刷新事件（`SiteRefreshed`，全站刷新完成）更新；启用插件时自动做一次静默基线；
- **下载种子时**（`DownloadAdded` 事件）**直接读取插件内部站点状态**判定：站点分享率**高于上限** → 立即限制该种子上传速度；否则不做任何操作（不再实时查询 MoviePilot 站点数据）；
- **站点分享率刷新后**：分享率 **≤ 下限** → 取消该站所有种子的上传速度上限；**> 上限** → 将该站未限速的种子批量补限速；
- 记录每个站点的档位状态，**仅在档位发生变化时通知**（分享率过低 / 已达到上限）；
- 详情面板展示每个配置站点的**分享率与相对上下限的档位状态**（即下载时判定限速的数据来源），以及每颗种子的限速标识；
- 停用/卸载插件时自动将本插件限速过的种子恢复为不限速（跨会话持久化 + 失败兜底重试）。

## 配置说明

| 配置项 | 说明 |
| --- | --- |
| 分享率下限 | 正数（>0，最多 1 位小数）。站点分享率 ≤ 下限时取消该站种子限速 |
| 分享率上限 | 正数（>0，最多 1 位小数，≥下限）。站点分享率 > 上限时新增限速 |
| 上传速度（KB/s） | 达到上限后的种子上传速度，默认 2000；0 表示不做限速处理 |
| 按站点单独分享率阈值 | 每行 `站点名称=分享率下限,分享率上限`，如 `馒头=0.8,2.0` |
| 下载器 | 多选 MoviePilot 中已配置的 qBittorrent 下载器 |
| 站点 | 多选；留空表示管理所有活动站点 |
| 发送通知 | 多选通知渠道；留空不通知。仅档位变化时通知 |

## 依赖

- MoviePilot 系统设置中已配置并启用的 **qBittorrent** 下载器；
- 已启用「**站点数据统计**」插件（用于抓取站点账号分享率并触发 `SiteRefreshed` 刷新事件）。

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「站点分享率上传限速」。

仓库目录结构：

```
plugins.v2/siteratiolimiter/__init__.py
package.v2.json
icons/Qbittorrent_A.png
```
