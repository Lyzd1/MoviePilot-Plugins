# 站点分享率上传限速（SiteRatioLimiter）

MoviePilot V2 插件：基于**站点账号分享率与分享率下限/上限（带滞回）**事件驱动地管理 **qBittorrent** 种子的上传限速。

## 功能

- **带滞回的档位状态机（防止限速波动）**：
  - 分享率 **≤ 下限 → 🔻 低于下限**：取消该站所有种子的上传速度上限，并**保持不限速直到分享率 > 上限**（不会一到下限之上就立刻限速）；
  - 分享率 **> 上限 → 🔺 达到上限**：将该站未限速的种子批量补限速，并**保持限速直到分享率 ≤ 下限**（不会一降到上限之下就立刻取消限速）；
  - 处于 **（下限, 上限] 中间区间 → ⏸ 中间区间**：保持原档位状态（从哪边进入就维持哪边），不调用限速接口；
- **全局分享率下限/上限**，并可为每个站点单独设置（每行 `站点=下限,上限`，未配置的站点回退全局值；兼容旧版单值 `站点=下限`，上限继承全局）；
- 插件内部维护每个站点的档位状态，由「站点数据统计」插件的分享率刷新事件（`SiteRefreshed`，全站刷新完成 `site_id == *`）更新；启用插件时做一次静默基线（不通知）；
- **下载种子时**（`DownloadAdded` 事件）**直接读取插件内部站点状态**判定：仅当站点档位为「达到上限」→ 立即限制该种子上传速度；其余档位不做任何操作（不再实时查询 MoviePilot 站点数据）；
- 记录每个站点的档位状态，**仅当档位跨边界变化时通知**（分享率过低 → 取消限速 / 达到上限 → 新增限速）；
- **保存配置时避免无意义的限速 API 调用**：仅当「上传限速大小变化、分享率阈值变化（导致档位跨边界）、或站点/下载器范围变化」时才调用接口调整限速；否则只刷新站点分享率、档位与统计；
- 详情面板仅展示站点状态表：每个站点的**账号分享率 / 数据日期 / 阈值（下限-上限）/ 档位状态 / 已限速种子数**。
  注意：**档位状态列是带滞回记忆的执行策略**（🔻 不限速保持 / 🔺 限速保持 / ⏸ 中间区间保持现状），
  不一定等于“当前分享率与阈值的直接比较”——如分享率回升到中间区间后仍会保持上一档位直到越过边界；
- **限速归属登记防抖动**（v1.3.2）：批量限速时对“已限速”的种子同样登记为“本插件限速中”，
  兜底恢复重试只处理真正不该再限速的种子，不会再每轮把本应保持限速的种子取消后再限速；
- 停用/卸载插件时自动将本插件限速过的种子恢复为不限速（跨会话持久化 + 失败兜底重试）。

## 档位与滞回示例

```
分享率下限=1.0，分享率上限=5.0
  ratio 0.8  → 🔻 低于下限：取消限速
  ratio 2.0  → ⏸ 中间区间：保持现状（仍不限速）
  ratio 4.5  → ⏸ 中间区间：仍保持现状（不恢复到限速！）
  ratio 5.5  → 🔺 达到上限：恢复限速
  ratio 4.0  → ⏸ 中间区间：保持现状（仍限速）
  ratio 0.9  → 🔻 低于下限：取消限速
```

## 配置说明

| 配置项 | 说明 |
| --- | --- |
| 分享率下限 | 正数（>0，最多 1 位小数）。分享率 ≤ 下限 → 取消该站种子限速 |
| 分享率上限 | 正数（>0，最多 1 位小数，≥下限）。分享率 > 上限 → 恢复该站种子限速 |
| 上传速度（KB/s） | 达到上限后的种子上传速度，默认 2000；0 表示不做限速处理 |
| 按站点单独分享率阈值 | 每行 `站点名称=分享率下限,分享率上限`，如 `馒头=0.8,2.0` |
| 下载器 | 多选 MoviePilot 中已配置的 qBittorrent 下载器 |
| 站点 | 多选；留空表示管理所有活动站点 |
| 发送通知 | 多选通知渠道；留空不通知。仅档位跨边界变化时通知 |

## 依赖

- MoviePilot 系统设置中已配置并启用的 **qBittorrent** 下载器；
- 已启用「**站点数据统计**」插件（用于抓取站点账号分享率并触发 `SiteRefreshed` 刷新事件）。
  分享率数据通过 `SiteOper.get_userdata_by_date` 按站点名读取（与「站点流量管理」「魔力兑换助手」一致），
  插件不自爬站点数据；若未安装/未启用该插件，面板将显示「⚪ 无数据」且不做限速。

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「站点分享率上传限速」。

仓库目录结构：
