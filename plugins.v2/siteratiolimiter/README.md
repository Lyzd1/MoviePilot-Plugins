# 站点分享率上传限速（SiteRatioLimiter）

MoviePilot V2 插件：基于**站点账号分享率与分享率下限**事件驱动地管理 **qBittorrent** 种子的上传限速。

## 功能

- **档位仅两档**：分享率 **≤ 下限 → 🔻 低于下限**（取消该站所有种子的上传速度上限）；**> 下限 → ✅ 正常**（该站全部种子进行限速）；
- **全局分享率下限**，并可为每个站点单独设置（每行 `站点=下限`，未配置的站点回退全局值）；
- 插件内部维护每个站点的档位状态，由「站点数据统计」插件的分享率刷新事件（`SiteRefreshed`，全站刷新完成 `site_id == *`）更新；启用插件时做一次静默基线（不通知）；
- **下载种子时**（`DownloadAdded` 事件）**直接读取插件内部站点状态**判定：站点档位为「正常」→ 立即限制该种子上传速度；否则不做任何操作（不再实时查询 MoviePilot 站点数据）；
- 记录每个站点的档位状态，**仅在档位发生变化时通知**（分享率过低 → 取消限速 / 恢复限速）；
- **保存配置时避免无意义的限速 API 调用**：仅当「上传限速大小变化、分享率下限阈值变化（导致档位变化）、或站点/下载器范围变化」时才调用接口调整限速；否则只刷新站点分享率、档位与统计；
- 详情面板仅展示站点状态表：每个站点的**账号分享率 / 数据日期 / 分享率下限 / 档位状态 / 已限速种子数**（已限速种子数按下载器实际当前限速统计，动作后刷新，不再显示 0）；
- 停用/卸载插件时自动将本插件限速过的种子恢复为不限速（跨会话持久化 + 失败兜底重试）。

## 配置说明

| 配置项 | 说明 |
| --- | --- |
| 分享率下限 | 正数（>0，最多 1 位小数）。站点分享率 ≤ 下限 → 取消该站种子限速；> 下限 → 全部限速 |
| 上传速度（KB/s） | 正常档位种子的上传速度，默认 2000；0 表示不做限速处理 |
| 按站点单独分享率下限 | 每行 `站点名称=分享率下限`，如 `馒头=0.8`；兼容旧版 `站点=下限,上限`（只取下限） |
| 下载器 | 多选 MoviePilot 中已配置的 qBittorrent 下载器 |
| 站点 | 多选；留空表示管理所有活动站点 |
| 发送通知 | 多选通知渠道；留空不通知。仅档位变化时通知 |

## 依赖

- MoviePilot 系统设置中已配置并启用的 **qBittorrent** 下载器；
- 已启用「**站点数据统计**」插件（用于抓取站点账号分享率并触发 `SiteRefreshed` 刷新事件）。
  分享率数据通过 `SiteOper.get_userdata_by_date` 按站点名读取（与「站点流量管理」「魔力兑换助手」一致），
  插件不自爬站点数据；若未安装/未启用该插件，面板将显示「⚪ 无数据」且不做限速。

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「站点分享率上传限速」。

仓库目录结构：

```
plugins.v2/siteratiolimiter/__init__.py
package.v2.json
icons/Qbittorrent_A.png
```
