# 剧集选集守卫（EpisodeSelectGuard）

MoviePilot V2 插件：覆盖 MoviePilot 原生按集拆包覆盖不到的空档——**「前 N 集试看」订阅**（从第 1 集起、订阅总集数小于 TMDB 整季）若选中了覆盖整季的 qBittorrent **大包种子**，自动做**文件级选集**——只下载订阅范围内的集，超范围文件剔除（不下载但保留在任务中），并打上自定义标签（默认 `Losing`）防止自动辅种。

适合「预订阅 / 试看」：例如一部 13 集的剧，你只订阅「总集数=3」，MoviePilot 往往给你选中 E01-E13 的大包。本插件会自动把它拆成只下 E01-E03。

## 解决的问题

MoviePilot 原生只有在下载链能算出「本次缺哪些集」时才会下发 episodes 给 qBittorrent 做文件级拆包。当你**只设置订阅总集数（从第 1 集起）、库里又全空**时，下载链把整季当「全缺」，不会拆包 → 大包整包下载。本插件在 `DownloadAdded` 事件后接管，用订阅记录的 `total_episode` 反推出应下载范围并强制文件级选集。

## 拦截边界（什么情况会触发）

**只有同时满足以下条件才会拦截：**

1. 下载来源是**订阅**（source 前缀 `Subscribe|`，或能按 tmdbid+季匹配到订阅记录）；
2. 媒体是**电视剧**；
3. 订阅记录 **`start_episode = 1`**（从第 1 集起）；
4. 订阅**总集数 < TMDB 当前整季总集数**（即「试看前 N 集」，而非全集订阅）；
5. MoviePilot **未原生按集拆包**（DownloadAdded 事件的 `episodes` 为空）；
6. 下载的种子里存在**集号超出订阅范围**的视频文件。

**以下情况不拦截**（交给 MoviePilot 原生或不做改动）：

- `start_episode > 1`（从第 N 集开始追某段）——原生会下发该段集数给下载器做文件级拆包；
- 全集订阅（`total_episode ≥ TMDB 整季`）；
- DownloadAdded `episodes` 非空（MoviePilot 已做原生拆包）；
- 非订阅来源下载（手动搜索 / 直接加种 / 辅种 / 刷流）；
- 电影；订阅未设有效集数范围；种子集数本身都在订阅范围内。

### 实现要点（v1.0.3）

- **订阅快照**：订阅「前 N 集试看」下完 N 集后会被 MoviePilot 立即完成并删除，DownloadAdded
  异步处理时已查不到订阅记录。插件在 `SubscribeAdded` / `SubscribeModified` 事件时把订阅的
  tmdbid/季/start/total 快照到插件数据，DownloadAdded 时从 `Subscribe|{...}` source + 快照
  解析目标范围，不受订阅删除影响。
- **TMDB 整季数现拉**：DownloadAdded context 的 `seasons` 会被 MoviePilot 清空（不可靠），
  判定「试看 vs 全集」时会按需现拉一次 TMDB（口径与 MoviePilot 一致：季集数长度）。

## 工作流程

1. 监听 `DownloadAdded`，按上述边界判断是否命中；
2. 读取对应订阅记录 → 目标集 = `range(1, total_episode + 1)`；
3. 读 qBittorrent 文件清单，逐视频文件名解析集号：
   - 集号**完全不在**目标范围的视频文件 → `priority=0`（不下载，保留在任务中便于恢复整包）；
   - 命中范围 / 无法解析集号 / 多集合一文件 → 保守保留，无法拆的会在面板标记；
4. 打标签（默认 `Losing`）+ 恢复下载；
5. 登记「选集状态」到插件数据，详情面板展示，可一键「补全下载」。

## 面板「补全下载」的智能决策

| 情况 | 判定 | 动作 |
|---|---|---|
| 该种子自身覆盖 TMDB 整季全集（种子文件集号 ≥ TMDB 整季范围） | 种子覆盖全集 | **恢复整包**：全部文件 `priority=1`、移除 `Losing`，用现有种子补齐全集 |
| 该种子只是部分集 / 缺集包 | 种子未覆盖全集 | **自动重新全集订阅**：不带 start/total，按 TMDB 全集重新发起原生订阅（MoviePilot 自动搜索缺失集） |

> 决策前若记录的 TMDB 总集数**缺失或小于 5**（连载剧 TMDB 更新不及时），会自动重拉一次 TMDB 总集数再判断。

面板同时提供「恢复整包」「重新全集订阅」「删除记录」三个独立按钮，以及每条记录的：
- 保留集（已剔除范围之外的集）
- 种子实际覆盖集（从种子文件解析出的全部集）
- TMDB 整季总集数
- 覆盖判断结论

## 配置项

| 配置 | 说明 |
|---|---|
| 启用插件 | 总开关 |
| 仅处理订阅来源下载 | 默认开启：只处理订阅触发的下载，手动搜索/辅种/刷流不干预 |
| 选集后自动恢复下载 | 默认开启：剔完超范围文件后自动 resume；关闭则保留暂停 |
| 选集标签 | 打在「被选集过（任务不完整）」的种子上；默认 `Losing`，留空不打 |
| 处理延迟(秒) | 事件到达后延迟处理，给 qBittorrent 任务元数据就绪留时间（默认 3） |
| 处理完成发送通知 | 默认关闭 |

## 依赖与兼容

- 面向 **MoviePilot V2（2.x 生产版，plugins.v2 目录）**；
- 仅支持 **qBittorrent** 下载器；
- 数据保存在插件自有数据目录（`save_data`），保留最近 200 条记录。

## 注意事项

- 被剔除的文件只是 `priority=0`，**不会被删除**；需要时「恢复整包」可全部找回；
- `start_episode > 1` 与全集订阅不会触发本插件，交给 MoviePilot 原生处理；
- 下载已完成入库的种子记录仍保留在面板（便于补全/清理），可手动删除。
