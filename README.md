# MoviePilot-Plugins

MoviePilot 插件集，包含自用及第三方适配的各类功能插件，涵盖下载管理、刷流、订阅、云盘同步等多个领域。

## 安装方式

将本仓库的 `package.v2.json` 地址添加到 MoviePilot 的插件仓库中即可自动获取所有插件。

```
https://raw.githubusercontent.com/Lyzd1/MoviePilot-Plugins/main/package.v2.json
```

## 插件列表

### 刷流

#### BrushFlowMod — 站点刷流(修改版)
- **版本**: v4.4.2-mod
- **功能**: 自动托管刷流。支持站点独立配置、促销过滤、HR排除、动态删种阈值、自动归档、带宽采样、多站点顺序/随机刷流、联动自动宣告等丰富功能。
- **标签**: `刷流` `仪表板`
- **说明**: 基于 `BrushFlow v4.4.2` 修改，重命名避免与原版冲突。

### 订阅

#### SubscribeGroup — 订阅规则自动填充
- **版本**: v3.3.5
- **功能**: 电视剧下载后自动添加官组等信息到订阅；添加订阅后根据二级分类名称自定义订阅规则。支持副标题匹配、视频来源识别、保存路径变量等高级功能。
- **标签**: `订阅`

### 云盘同步

#### OpenlistMover — Openlist 视频文件同步
- **版本**: v4.7.1
- **功能**: 监控本地目录，当有新视频文件生成时，自动通过 Openlist API 将其移动到指定的云盘目录。支持洗版模式、移动延迟配置、额外文件复制到 STRM 目录、失败重传等。
- **额外文件优先上传（按目录上传队列）**: 以单个目录（一张专辑/一部剧）为单位区分两类文件。①额外后缀文件（如 .lrc/.txt/.png/.jpg/.yaml/.ass）一出现即经过短暂稳定性检查（最多 3 秒、大小连续 1 秒不变）立即上传，上传成功后触发一次「归队」。②音视频文件稳定后各自按「稳定时刻 + 移动延迟」独立等待（pending 独立媒体），不会自动并入已有队列，也不会因其它文件出现而重置倒计时，到点即提交。归队规则：若同目录有尚未开始上传的队列，则把所有 pending 媒体按 ready_at 升序追加到队尾并重置 deadline；若已有队列均已开始上传，则用当前 pending 新建队列（旧队列继续按自身节奏传完，互不影响）；没有队列时仅在有 pending 时新建。批次队列只有在该目录内不再存在额外文件、且没有额外文件正在上传/等待 STRM 回拷，并到达 deadline 后，才按 FIFO 每轮放行一个，队列清空即删除；等待额外文件超过「队列等待上限」会告警并放行。可通过「额外文件优先上传」开关关闭，恢复 4.6.9 的逐文件延迟行为。
- **标签**: `云盘同步`

#### RemoveLink — 清理媒体文件
- **版本**: v3.1
- **功能**: 媒体文件清理工具，支持硬链接文件清理、STRM 文件清理、刮削文件清理（元数据/图片/字幕）、转移记录清理、种子联动删除、空目录清理、延迟删除防误删等功能。
- **标签**: `云盘同步`

#### StrmCleaner — StrmCleaner
- **版本**: v1.5
- **功能**: 监控 STRM 文件及文件夹删除，联动清理 openlist/local 云盘文件及元数据。支持视频/音乐自动识别、防雪崩保护。
- **标签**: `云盘同步`

### 音乐

#### 多源歌词 — MusicLyricsMulti
- **版本**: v1.2.0
- **功能**: 聚合网易云 / QQ 音乐 / 酷狗三源歌词，严格匹配（标题 + 艺人 + 时长）并按时间戳合并双语；只向宿主提供歌词候选，不写任何文件。
- **标签**: `音乐` `歌词`
- **说明**: 通过 `get_module()` 声明 `music_lyrics` / `music_lyrics_candidates`，由宿主刮削链择优落盘。

### 分享率

#### BonusExchangePlugin — 魔力兑换助手
- **版本**: v2.2
- **功能**: 自动监控分享率，在低于阈值时执行魔力兑换操作。支持馒头等站点。
- **标签**: `分享率`

### AI

#### PromptEditor — AI提示词编辑器
- **版本**: v1.2
- **功能**: 编辑 AI 助手的提示词并清空缓存使其立即生效。
- **标签**: `AI`

### 消息通知

#### MediaServerMsg — 媒体库服务器通知（TV剧集入库通知去重）
- **版本**: v2.1.4
- **功能**: 发送 Emby/Jellyfin/Plex 的播放、入库等通知；TV 剧集入库时首条立即通知，设置的秒数内同一部剧的后续入库不再重复通知。
- **标签**: `消息通知` `媒体库`
- **说明**: fork 自 jxxghp/MoviePilot-Plugins v2.1.3。
